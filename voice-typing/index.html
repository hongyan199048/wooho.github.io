轻度起

去语气词

「嗯」「呃」「啊」这类填充词直接去掉。中度起还会清掉「那个」「就是说」「然后就是」等口头禅。

中度起

识别改口

说到一半改主意，只保留你最后想说的那版。「去延津……不对，盐津」输出就是「盐津」。

中度起

自动排版

说到「第一……第二……」「首先……然后……最后」时，自动排成编号列表，不用手动整理。

全档位

安全网

FAQ
常见问题
支持哪些系统？
Linux 桌面，需 X11（在终端运行 echo $XDG_SESSION_TYPE 应为 x11）。Ubuntu、Fedora、Debian 等均可，Wayland 下快捷键与粘贴可能失效。
需要自己申请 API Key 吗？
需要。识别引擎选其一：阿里云百炼（Paraformer）或火山引擎豆包。润色模型（DeepSeek / 智谱 GLM / MiniMax）各自另有 Key，也可完全关闭。
三档润色强度怎么选？
轻度：只去「嗯呃啊」、补标点、分段，内容一字不改，适合逐字记录。
中度：再加去口头禅、识别改口、并列要点排成列表，日常默认。
重度：再加按上下文修正明显错词，适合说错字多的场景。
润色会不会改掉我想说的话？
两种保护。一是 prompt 明确禁止添加原文没有的内容、禁止总结合并、禁止把不同措辞的强调当冗余删掉；二是润色调用失败或超时直接回退识别原文，不会丢字。你也可以完全关闭润色，只走识别。
我的语音数据会上传吗？
云端识别会把音频发送给你所选引擎做实时转写，但不会被存储、不用于训练，转写完成后立即丢弃。历史记录只存在你本地的配置文件里。
在哪些应用里能用？
任何能打字的 App——浏览器、聊天软件、代码编辑器、Office、邮件客户端等。文本通过剪贴板粘贴注入，无需插件或集成。
免费吗？
软件本身开源免费（MIT License），没有账号、没有订阅、没有字数上限。API 调用按各引擎的计费规则收取，费用由你直接支付给引擎服务商。
